# Basic_Chatbot
A Basic Rule-Based Chatbot built using Python that interacts with users through predefined responses. It uses conditional statements, functions, loops, and input/output to handle simple conversations such as greetings, questions, and goodbye messages. This project demonstrates fundamental Python programming concepts.

# About the Project

A simple rule-based chatbot built using Python that interacts with users through predefined responses. It responds to greetings, answers basic questions, and ends conversations.

# Features
Responds to greetings.
Answers basic questions.
Provides goodbye messages.
Continues the conversation until the user exits.
# Technologies Used
Python 3
If-elif-else statements
Functions and loops
Input and output
# How to Run
Download or clone the repository.
Open the project folder.
Run the following command:
python chatbot.py
